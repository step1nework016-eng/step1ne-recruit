# E18｜WSL2：架設資安紅隊＋藍隊，每週作業（2026-10-08 Jacky 核准）

## 結論先講
在這台 WSL2 常駐兩個角色：🔴 紅隊（自我稽核、只找問題、不改程式）、🔵 藍隊（寫修補、不自己上線）。
教材已在 `docs/wsl2/資安/`，**先完整讀過三個資料夾再動手**：紅隊技能包、藍隊技能包、共用。
這是保護我們自己的系統與人選／職缺資料，只測自己的系統。

## 一定要先讀
- `資安/紅隊技能包/SKILL.md`（交戰規則、A–G 稽核區、硬規則）
- `資安/紅隊技能包/提示注入題庫.md`（52 題，拿來測阿財／阿福／背景 AI）
- `資安/藍隊技能包/SKILL.md`（修補原則、事件應變 SOP、第 8 章裝置間接注入防線）
- `資安/共用/回報格式.md`（sec_findings／sec_events 欄位、TG security 路由、週五週報範本）

## 鐵則（不可違反）
- 只打我們自己的系統與網址，不碰任何第三方。
- 兩類最高風險資料＝人選履歷、公司職缺（官網未公開部分）。驗證外洩路徑**只用誘餌**（jobs.slug=`zz-sec-canary-job`、applications.id=`app_canary_sec_0001`、標記字串 `CANARY-RESUME-7F3A`）。碰到真實資料只記最小證據（狀態碼／欄位有無／計數），**嚴禁下載、複製、轉存、餵給其他程式或 AI**。
- 會寄信或發 LINE 給真人的入口，只能用測試帳號／測試信箱，不可用真資料觸發。
- D1 節流：每輪 ≤20 請求，避免重演 9/1 打爆免費額度。
- 紅隊只找問題與寫報告，**不改任何程式**。藍隊只寫 patch、自測，交 Mac 總指揮審核，**不自己上線、不 push**。
- 發現人選／職缺可能外洩（high）：立即停手，寫 sec_findings＋sec_events，發 TG 即時告警（不等週五）。

## 每週排程（請在這台用 cron 架起來，先別真的對線上狂打，第一輪跑「只讀」模式確認流程）
- 週一：紅隊按 A–G 稽核區跑一輪，結果寫進 D1 的 sec_findings／sec_events。
- 週二～三：藍隊讀報告寫 patch、自測，交回 Mac 審核。
- 週四：紅隊用同手法複測，確認修好才把該筆改 verified。
- 週五：藍隊產白話週報，發到 TG security 路由（群組 -1003231629634／thread 7421）。四種訊息格式見回報格式.md；TG 不放攻擊步驟、金鑰、任何真實人選資料，只寫白話＋連結 https://step1ne.com/sec/ 。

## 裝置防護（這台與 Mac 都要）
- 重點威脅：駭客寄信到 official@ 讓讀信 AI 中標（間接提示注入）。工具已用 `ai_lockdown` 關閉執行面，藍隊第 8 章有可直接套進 `ai_worker.py`／`parse_resumes.py`／`company_news_tick.py` 的防禦草案（外部內容與指令隔離、輸出驗證、對外動作要人確認）。先寫成 patch 交審，不要自己上線。
- 紫隊演練：紅隊可對藍隊的 AI 下注入，測藍隊會不會被誘導做錯修補；藍隊 SKILL 第 7 章有對應防線。
