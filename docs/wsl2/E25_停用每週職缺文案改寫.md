# E25｜Jacky 10/12：停掉每週一的職缺文案改寫（jobcopy）

## 結論
停用 `step1ne-jobcopy.timer`（每週一 09:00 跑 `job_copy_loop.sh`）。Mac 那份 launchd 已於 10/12 停用。

## 理由（Mac 查 log）
- 8/31、9/7、9/14、10/5 四輪：同一批職缺每週都再改 1～10 處，沒有收斂；一輪 1～4.5 小時。
- 改 jobs 會更新 `updated_at` → 阿財 `invalidate_stale_prepared()` 把已備好的題目計畫與開場白作廢（剛做的「進房秒開場」會被週一這支打回原形）。
- 沒有任何成效數據顯示它讓應徵變多。

## 要你做
1. 如果今天 09:00 這輪**還在跑**：等它目前這個職缺做完（看 log 換到下一個職缺的那一刻）就停掉，不要中途砍在寫入一半。
2. `systemctl --user disable --now step1ne-jobcopy.timer`，確認 `list-timers` 已經沒有它。
3. 不要刪腳本；之後新職缺上架要稽核，改成人工指定單一職缺手動跑。
