# E26｜Jacky 10/12：中高階職缺優先「從公司找人」

## 結論
中高階職缺（`jobs.seniority='senior'`，或年薪下限 ≥ 100 萬／月薪下限 ≥ 8 萬）每一場找人，**第一步先定目標公司，再從這些公司的現任／前任對應職能主管裡找人**；不要再只用職稱關鍵字搜 LinkedIn。
起因：10/11～10/12 美德三個主管缺（group-it-head、phnom-penh-office-head、business-operations-manager）兩天 0 筆。

## Mac 查到的事實
- `job_sourcing_settings.target_companies` 欄位已存在，`business-operations-manager`、`phnom-penh-office-head` 已有清單（紡織成衣、製鞋、柬埔寨台商廠）。
- **但夜間找人的 `nightly_pipeline/prompts/sourcing.md` 完全沒讀這個欄位**（只有舊的 `talent_sourcing_agent.py:614` 有讀）→ 填了等於沒用。

## 要你做
1. `sourcing.md` 第二步（讀職缺）後加「中高階：公司優先」段落：
   - 讀 `SELECT target_companies, target_titles FROM job_sourcing_settings WHERE job_slug=…`。
   - 有清單：每家公司用「公司名（中英）＋對應職能職稱」搜，例如「台南企業 柬埔寨 廠長」「Pou Chen Cambodia general manager」；前任也算（LinkedIn 經歷欄）。
   - 沒清單：先在本場**自己建 10～15 家目標公司地圖**（依「產業型態 × 職能 × 是否有海外據點」推，每家寫一句為什麼），印成 `COMPANYMAP {...}` 一行到 log，並存 `nightly_pipeline/state/company_maps/<slug>.txt`（有就沿用、累加，不要每輪重建）。
   - 找到合格人選時，把他待過的公司也加進地圖（種子擴張）；但**不能反過來用「待過某公司」推定他有某能力**，逐條對照照舊。
   - 職稱關鍵字搜尋留作補充，搜尋次數上限不變（20）。
2. 目標公司**不可以**是客戶本身或其關係企業、也不可以是 `off_limits_note` 列的公司（照舊擋）。
3. 每場結尾 FUNNEL 加欄位：`company_first`（是否走公司優先）、`companies_searched`（搜了幾家）。
4. 用 dry-run 跑一次 group-it-head，把產出的公司地圖貼進回報讓 Mac 看合不合理；Mac 確認後會把好的地圖寫進 D1 `target_companies`。

## 規矩不變
不聯絡任何人、資料庫只新增、沒個人頁不收、年齡性別外貌不判斷、阿財面談中不開新場。
