# E28｜Jacky 10/12：遊戲橘子職缺雲端表自動比對（WSL2 跑）

## 結論
新程式 `client_sheet_watch.py`：每天 15:00 讀遊戲橘子每週更新的 Google 職缺表（公開連結，不用登入），跟我們 jobs 比對，
有「新職缺／內容改了／我們開著但表上沒了」才推 TG（客戶群組「職缺」主題，tg_routes key=client_jobs）；每週一固定推一次總覽。
Mac 不排程，只有 WSL2 跑。

## 要你做
1. `git pull`
2. 先試跑（不推 TG、不存快照）：`python3 client_sheet_watch.py --dry`
   預期（10/12 當下）：表上 4 個；🆕 專案經理（若 Mac 那邊已上架就不會出現）；⚠️ 4 個（遊戲客服專員、總機接待、測試產品專員、新聞社群編輯）。
3. 建 systemd user timer `step1ne-sheetwatch.timer`：每天 15:00（Asia/Taipei）跑 `python3 client_sheet_watch.py`，`Persistent=true`。
   service 的 WorkingDirectory 用 repo 目錄，環境跟其他 step1ne timer 一樣（要讀 ~/.config/workflow-os/step1ne-tg.env 跟 D1 HTTP 設定）。
4. 手動跑一次正式版：`python3 client_sheet_watch.py --weekly`（會推第一則 TG 總覽、存第一份快照）。
5. `systemctl --user list-timers | grep sheetwatch` 確認排上。

## 注意
- 表讀不到（客戶改成不公開）會推「⛔ 職缺表讀取失敗」，不要自己重試到天荒地老。
- 技術職（工程師／開發）本來就不在這份「非技術派遣」表，已用 exclude_regex 排除，不會誤報成「表上沒了」。
- 之後別的客戶也有這種表：在 D1 `client_sheet_watch` 加一列（client_id、label、sheet_id、gids、exclude_regex）就好，不用改程式。
