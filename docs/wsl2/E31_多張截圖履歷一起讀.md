# E31：一份履歷好幾張截圖——阿財要讀到全部頁數

2026-10-12 Mac 交辦。Jacky 已核准（應徵表單 BETA 改版的一部分）。

## 背景（一句話）

Jacky：現在很少紙本履歷，最常見是**把 PDF 履歷截圖上傳**，一份好幾頁就是好幾張截圖。
原本只有第 1 張會被看圖轉文字（OCR），第 2 張以後放在 `resume_extra_files` 沒人讀——阿財只看得到第一頁。

## ⚠️ 最重要：WSL2 的 parse_resumes.py 一定要換成新版

Mac 的 launchd 排程找不到 `claude` 指令（PATH 沒有 ~/.local/bin），**截圖／照片的 OCR 實際上全部是 WSL2 在做**。
WSL2 還是舊版的話，多張截圖只會轉第 1 張、也不會判斷「看不清楚」。所以第一步就是 `git pull`。

## Mac 已經做好的（你只要 `git pull`）

1. **parse_resumes.py**（Mac 每 90 秒跑、WSL2 也跑，兩台用 deploy_locks 搶號）：
   第 1 張（`resume_file_id`）是圖片時，連同 `resume_extra_files` 裡沒標 `retired` 的截圖，**照上傳順序一起 OCR**，
   合成一份文字寫回第 1 張的 `files.text_content`。`fetch_application.py` 不用改（它本來就讀這欄）。
   - 最後一張進來 45 秒內先不看（LINE 一張一張傳，等他傳完）。
   - 看圖期間又多一頁 → 這輪結果先寫、`parsed_at` 留空，下一輪整組重做。
   - **字太少＝看不清楚**（中文 < 150 字 而且 有意義字數 < 300）：
     第 1 次 → `resume_read_checks.state='unreadable'`，LINE 傳的會推「照片有點看不清楚，可以再截一次圖（整頁、字大一點）嗎？」
     （呼叫 recruit worker `/internal/resume-unreadable`，金鑰讀 `~/.config/workflow-os/recruit.env`）；網頁傳的由表單提示。
     第 2 次 → `accepted_low`：收下、TG 請顧問看原圖，不會一直擋。
   - 寫完文字會把預熱開場白／題目計畫的時間戳設成 2000-01-01（跟 Worker 的 markPrepStale 同一招）。
2. 新表 `resume_read_checks`（已在 D1 建好，schema 在 `schema_resume_intake.sql`）。
3. Worker（public／recruit）都已部署：網頁可一次傳多張截圖；LINE 第 2 張以後會觸發整組重看。

## 要你做的（interview_daemon.py 小修，Mac 不動 daemon）

E30 的 `_late_refresh()` 只在「履歷換了一份（resume_file_id 變了）」才重抓快取。
多張截圖的情況是**同一個檔案、文字被重寫**（只有 `files.parsed_at` 會變），快取看不到。

```bash
cd ~/claude-projects/工作流程技能包/step1ne-recruit   # WSL2 上的路徑
git pull
git apply docs/wsl2/patches/interview_multi_page_resume_refresh_20261012.patch
python3 -c "import ast;ast.parse(open('interview_daemon.py').read())"
# 重啟阿財 daemon
```

patch 內容（只動 `_late_refresh()` 一處）：
- 比對的 key 多加 `files.parsed_at`；
- 面談**還沒開始**的，就算快取裡已經讀得到履歷，也每 30 秒看一次 key（第一次只記、不重抓）；
- 面談開始後不換（避免中途資料變動）。

另外，如果 WSL2 上 `parse_resumes.py` 有排程：`git pull` 後就是新版，不用改排程。
WSL2 那台要有 `~/.config/workflow-os/recruit.env`（`RECRUIT_API_URL`、`RECRUIT_ADMIN_TOKEN`）才推得了 LINE「再截一次」；
沒有的話只會印一行「LINE 沒推成功」，其他照常。

## 驗收

- 用測試應徵（不要用真人），網頁 `/resume/?t=<chat_token>` 一次傳 2 張截圖：
  2 分鐘內 `files.text_content`（第 1 張）出現兩頁合併的文字、`parse_note` 寫「OCR 轉錄（截圖／照片 2 張）」。
- daemon log 出現「🔄 …又多了幾頁…快取整份重抓」（如果那筆已經在快取裡）。
- 做完把測試資料清掉，回報 Mac。
