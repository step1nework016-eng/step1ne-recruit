# E32｜Jacky 10/12 核准：阿財面談技巧四項改進（張景勛 10/6 那場復盤）

## 背景（Mac 復盤 messages 逐句看過）
張景勛（0916e995…，營運發展主管，10/6）那場：
1. **同一題重問**：預告期問兩次（他答「提離職到交接需要2個月」後又問「方便拆開講嗎」→「不知道」）；ESD 採購細節問兩次（答「鴻海」後原句再問一次「方便具體說一下嗎」）。
2. **一直答「沒有」還往下追**：數據分析連問三層（獨立分析→整理報表→看過報表），三次都「沒有」；主導專案、談判堅持條件也是。候選人體感是被考倒，浪費提問額度。
3. **該問沒問**：沒問「為什麼想離開鴻海（才 1 年 7 個月）」、沒問「能不能從印度搬回台灣」。
   查到原因：動機（推力／拉力）只寫在 `_senior_mustdo_lines()`，而它只在 `job_expertise.acai_v2=1` 的職缺生效——**46 個職缺只開了 2 個**，其他職缺根本不會問離職原因。
4. **薪資逼問**：他答「面議」→再問→「面議」→「還在線上嗎…請提供數字」→「不方便」。共問 3 次。

（另：「還在線上嗎」誤判已在 10/6 4c44a81 修好，10/7 起復發 0 次，不用再處理。）

## 要你改（interview_daemon.py，改完 Mac 審 patch 再上）
A. **同一題不重問**：每輪送 prompt 前，把「這場已經問過的主題」列成清單放進提示（例如從阿財訊息與報告草稿抽：預告期、競業、出差、產業經驗、空窗…）；明講「候選人已經回答過的題目，即使答得很短，也只能換角度追一次，不准用同一句或同義句重問」。
B. **連兩次否定就換題**：同一主題候選人連續兩次回答否定／不知道（沒有、不知道、無、沒做過…）→ 這個主題記為「缺」，直接換下一題，報告照實寫「本人表示沒有」。不要第三層追問。
C. **離職原因、搬遷可行性改成所有職缺必問**（不受 acai_v2 限制）：
   - 動機：至少問一題「為什麼想換」，在職的追問一句推力（現在哪裡想離開）＋拉力（這個職缺哪裡吸引）。
   - 居住地與職缺地點不同（例如人在海外、外縣市）→ 必問「能不能搬過來／多久可以過來」。
   - 時間不夠時，這兩題優先度高於「專業分級往上追問」。
D. **薪資最多問兩次**：表單已填或第一次答「面議」→ 第二次換說法（給區間選項或問現職大概待遇）；仍不給 → 記「本人不願透露」，交顧問電話問，不准第三次。
E. 收尾對候選人的評語不要說得像「通過」：英文測驗後不說「英文可以清楚表達」這類結論句，只說「謝謝，英文這段我記下來了」。
