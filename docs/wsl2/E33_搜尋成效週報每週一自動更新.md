# E33｜Jacky 10/12：搜尋成效週報每週一自動更新（搬到 WSL2）

## 目標
內部週報頁 https://step1ne.com/seo-report/（「搜尋成效週報」分頁）每週一 10:00 自動更新，**數字＋兩段文字**都要自動：
- 「這週做了什麼」：從上週官網改動紀錄自動整理（claude 改寫成白話；失敗就直接列改動標題）
- 「回收日與下一步」：從 `seo_report/followups.json` 自動排；日期過了會標「到期，要回頭看」
- AI 實測（geo）與額外商機：沿用上一份，Mac 有新結果時會寫進 `seo_report/overrides.json`

Mac 太弱，**不在 Mac 排程**。Mac 原本的排程（Claude 排程任務 `step1ne-seo-weekly-report`）在這份推上去後會停用。

## 程式在哪（都在這個 repo，git pull 就有）
`seo_report/`
- `run_weekly.sh`：整條流程（git pull → auto_notes → build_weekly → 寫 D1 → TG）
- `build_weekly.py`：抓 Google 搜尋（GSC）＋ GA4，產出當週快照
- `auto_notes.py`：自動寫「這週做了什麼／回收日」
- `publish.py`：寫進 D1 `seo_weekly_reports`（同一週重跑＝覆蓋，不會多一列），發 TG 摘要
- `log_action.py`：人工補充（見最下面）
- `notes/`：人工寫的 notes（某一週有人工版就優先用人工版，自動版跳過）
- `data/`：9/14～10/12 的歷史快照（存檔用，頁面讀的是 D1）

產出放 `~/aijob-automation/state/seo_report/`（**不寫進 repo**，免得擋到自動更新的 git pull）。

## WSL2 要做的
### 1. 拉程式＋裝套件
```bash
cd ~/claude-projects/工作流程技能包/step1ne-recruit && git pull origin main
python3 -m venv ~/.venvs/seo_report && ~/.venvs/seo_report/bin/pip install -q google-auth google-api-python-client google-analytics-data
mkdir -p ~/aijob-automation/state/seo_report ~/aijob-automation/logs
```
（`run_weekly.sh` 會自動用 `~/.venvs/seo_report/bin/python`；沒有 venv 就用系統 python3。）
確認 `~/claude-projects/step1ne-stopgap-site` 在（auto_notes 只會對它做 `git fetch`，不會動工作目錄）；不在的話它會自己只讀 clone 到 `~/aijob-automation/state/step1ne-site-ro`。
確認 `claude` 指令在 PATH（auto_notes 會用 `claude -p --setting-sources ''`，不吃全域 CLAUDE.md）。

### 2. 先跑 dry-run（不寫 D1、不發 TG）
```bash
cd ~/claude-projects/工作流程技能包/step1ne-recruit && bash seo_report/run_weekly.sh --dry-run --date 2026-10-12
```
要看到：`ok notes …`（10/12 有人工版會顯示「跳過」，正常）、`ok 2026-10-12 12 weeks 25 kw`、`[dry-run] TG 內容：` 三行數字。
再跑一次「下週」看自動文字長怎樣：`bash seo_report/run_weekly.sh --dry-run --date 2026-10-19`，把印出來的 notes 檔（路徑在 `ok notes … ->` 後面）內容貼進回報。

### 3. 真的寫一次 D1，但不發 TG（驗收寫入）
```bash
SEO_NO_TG=1 bash seo_report/run_weekly.sh --date 2026-10-12
```
這會把 10/12 那一列從 `mac-backfill` 覆蓋成 `wsl2-weekly`（內容一樣，只是改成這台產的）。確認：
```bash
python3 -c "import sys;sys.path.insert(0,'.');import d1_http;print(d1_http.query(\"SELECT report_date,source,created_at,length(data) n FROM seo_weekly_reports ORDER BY report_date DESC LIMIT 3\")['results'])"
```
10/12 那列 source＝`wsl2-weekly`、n 大於 15000。

### 4. 裝每週一 10:00 的排程
```bash
mkdir -p ~/.config/systemd/user
cat > ~/.config/systemd/user/step1ne-seo-weekly.service <<'EOF'
[Unit]
Description=Step1ne 搜尋成效週報（每週一）

[Service]
Type=oneshot
WorkingDirectory=%h/claude-projects/工作流程技能包/step1ne-recruit
Environment=TZ=Asia/Taipei
Environment=PATH=%h/.local/bin:%h/.nvm/versions/node/current/bin:/usr/local/bin:/usr/bin:/bin
ExecStart=/bin/bash seo_report/run_weekly.sh
TimeoutStartSec=1800
StandardOutput=append:%h/aijob-automation/logs/seo_weekly.log
StandardError=append:%h/aijob-automation/logs/seo_weekly.log
EOF
cat > ~/.config/systemd/user/step1ne-seo-weekly.timer <<'EOF'
[Unit]
Description=每週一 10:00（台灣時間）更新搜尋成效週報

[Timer]
OnCalendar=Mon *-*-* 10:00:00 Asia/Taipei
Persistent=true

[Install]
WantedBy=timers.target
EOF
systemctl --user daemon-reload && systemctl --user enable --now step1ne-seo-weekly.timer && systemctl --user list-timers | grep seo
```
`Persistent=true`：週一 10:00 電腦沒開，開機後會補跑；報告日期仍是那週的週一（run_weekly.sh 自己算）。

### 5. 驗收
- `list-timers` 顯示下次是 10/19（一）10:00。
- 10/19 跑完：`tail -30 ~/aijob-automation/logs/seo_weekly.log` 有 `ok d1`、`ok tg`；Jacky 收到 TG「📊 Step1ne 搜尋成效週報已更新（2026-10-19）」；step1ne.com/seo-report/ 下拉選單最上面是 2026-10-19。
- 失敗時會發 TG「⚠️ …這週沒更新成功」＋哪一步失敗，頁面維持上一週。

TG 去向：D1 `tg_routes` 有 key＝`seo_report` 就發那裡；沒有就發 Jacky 私訊（跟原本 Mac 排程一樣）。

## 給 Mac（或任何一台）：人工補充怎麼加
寫進 repo 檔案，commit＋push 後，WSL2 週一 git pull 就會用到：
```bash
cd ~/claude-projects/工作流程技能包/step1ne-recruit
python3 seo_report/log_action.py done "新文章" "〈試用期不合格可以資遣嗎？〉上線"     # 這週做了什麼（原文照用）
python3 seo_report/log_action.py followup 2026-11-20 "「派遣公司推薦」是否進前 10"   # 新增回收日
python3 seo_report/log_action.py followup "等 Jacky" "某件要他決定的事"              # 沒日期的
python3 seo_report/log_action.py list                                               # 看還沒做完的回收項目
python3 seo_report/log_action.py close f2                                           # 做完了（id 或一段文字）
python3 seo_report/log_action.py set extra_leads "某某公司：官網填表 → 開會"         # 額外商機那一行
python3 seo_report/log_action.py geo "「台灣獵頭公司推薦」（ChatGPT 登入）" "✓ 第 5 家" up   # 新一輪 AI 實測（同一天第一筆會換掉舊整組）
git add seo_report && git commit -m "週報：補充" && git push origin main
```
某一週想整份手寫：放 `seo_report/notes/<那週週一>.json`（格式照 `notes/2026-10-12.json`），自動版就會跳過。
