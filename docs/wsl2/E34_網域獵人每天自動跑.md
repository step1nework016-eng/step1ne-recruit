# E34｜Jacky 10/12：網域獵人每天自動跑（WSL2）＋結果進內部看板

## 目標
Jacky 自己的「網域獵人」工具包（找招募／飯店相關、可以用一般註冊價買到的 .com 老網域）每天 09:30 在 **WSL2** 自動跑，
結果顯示在內部看板 https://step1ne.com/seo-report/#domains（「網域追蹤」分頁 → 口袋名單）。**Mac 不跑**（太弱）。
有「新的、前世乾淨」的網域才發 TG 給 Jacky 私訊（8365775688），沒有就不吵他。

## 程式在哪（git pull 就有）
`domain_finder/`
- `CLAUDE.md`（＝`AGENTS.md`）：給跑任務的 Claude 看的完整規則與已知的坑。**先讀這份。**
- `每日任務提示詞.md`：每天交給 Claude 的任務（`run_daily.sh` 會自動填路徑）
- `run_daily.sh`：整條流程（git pull → `claude -p` 跑任務 → `sync_dashboard.py --tg`）
- `sync_dashboard.py`：名單 → D1 `site_settings` key＝`domain_pocket` → 看板；`--tg` 有新的乾淨網域才通知
- `agent_queue.py`／`add_scored.py`／`build_queue.py`／`make_html.py`／`find_domains.py`：工具包原本的工具
- `seed/`：第一次的起始資料（9 萬多個候選、391 個佇列、已知排除）

**會變動的資料放 repo 外面**：`~/aijob-automation/state/domain_finder/`（名單正本 `網域口袋名單.csv`、`cache/`）。
第一次跑任何一支程式會自動從 `seed/` 複製過去。不進 git，所以不會擋到自動 `git pull`。
名單每次同步都會整份寫進 D1，CSV 不見可以 `python3 domain_finder/sync_dashboard.py --restore-csv` 還原。

## ⚠️ 要 Jacky 自己做的一步：WSL2 的 Claude 連上「另一個」Ubersuggest 帳號

**白話**：Ubersuggest 是幫網域打分數的工具，一個帳號一天能查的次數是固定的。Mac 已經用了一個帳號；
WSL2 如果也登同一個，兩台是**搶同一份額度**，不會變快。所以 WSL2 要登**另一個帳號**（用另一個 email 註冊）。

> 要先知道的：每天能查幾個，看那個帳號的方案。Mac 那個帳號一天約 300 次；**新帳號如果是免費版，一天能查的次數會少很多**（確切數字我沒查證，以 Ubersuggest 帳號頁「Usage」為準）。
> 要不要為第二個帳號付錢是你決定；不付也能跑，只是一天查得少、慢一點查完。

步驟（WSL2 那邊的 Claude 會帶你做，你只要負責登入）：
1. 在 WSL2 的 Claude 說：「照 E34 幫我連 Ubersuggest」。它會跑這一行（加一個叫 ubersuggest 的連線，所有資料夾都能用）：
   ```bash
   claude mcp add --scope user --transport http ubersuggest https://ubersuggest-mcp.neilpatelapi.com/mcp
   ```
2. 你在 WSL2 終端機打 `claude`，進去後打 `/mcp` → 選 **ubersuggest** → **Authenticate**。
   會跳出瀏覽器 → **用另一個帳號登入**（不是 Mac 那個）→ 看到成功就關掉瀏覽器，打 `/exit` 離開。
   - 瀏覽器沒自己跳出來：把終端機上那串網址複製到 Windows 的瀏覽器打開。
   - 密碼只在 Ubersuggest 的網頁上輸入，不要貼進任何對話。
3. 回到 WSL2 的 Claude 說「好了」，它會跑檢查（不花額度）確認連上的是新帳號。

## WSL2 要做的
### 1. 拉程式
```bash
cd ~/claude-projects/工作流程技能包/step1ne-recruit && git pull origin main
mkdir -p ~/aijob-automation/state/domain_finder ~/aijob-automation/logs
python3 domain_finder/agent_queue.py status      # 會自動建資料夾；要看到「今天已查 0 個；佇列還剩 391 個」
which whois || sudo apt-get install -y whois     # 確認還能不能註冊要用 whois；沒有就裝（要 Jacky 輸入 sudo 密碼的話請他自己打）
```
確認 `~/.config/workflow-os/cf.env` 和 `step1ne-tg.env` 在（seo 週報已經在用，應該都在）。

### 2. 帶 Jacky 連 Ubersuggest（上面那段），然後檢查
```bash
bash domain_finder/run_daily.sh --check
```
要看到「ubersuggest 工具：有；登入狀態：…」，而且登入的帳號**不是 Mac 那個**（請 Jacky 看前三個字確認）。
說「沒有」：`claude mcp list` 看 ubersuggest 在不在、是不是 `✓ Connected`；不在就重做第 1 步；在但沒登入就重做第 2 步。
⚠️ `run_daily.sh` 用 `--setting-sources ''`（不吃全域 CLAUDE.md 的 agentacct 指令）＋`--permission-mode bypassPermissions`（因為拿不到 settings.json 的權限清單），
並設 `ENABLE_CLAUDEAI_MCP_SERVERS=false`（不載入 claude.ai 帳號的雲端 Ubersuggest——那是 Mac 那個帳號）。
用 `claude mcp add --scope user` 加的 ubersuggest 存在 `~/.claude.json`，不受這兩個影響。**如果 check 說「沒有」但 `claude mcp list` 有**，回報裡寫清楚，不要自己改成別的帳號的連接器。

### 3. 第一次手動跑（不發 TG）
要 2～3 小時（一輪 11 個、每輪等 5 分鐘），放背景跑：
```bash
cd ~/claude-projects/工作流程技能包/step1ne-recruit/domain_finder
nohup bash run_daily.sh --no-tg >> ~/aijob-automation/logs/domain_finder.log 2>&1 &
tail -f ~/aijob-automation/logs/domain_finder.log      # Ctrl+C 只是停止看，不會停掉任務
```
跑完要看到：Claude 的回報（「今天查了幾個…」）、最後一行 `ok 看板已同步：名單 N 筆；佇列剩 …、今天查了 …`。
確認 D1：
```bash
python3 -c "import sys,json;sys.path.insert(0,'..');import d1_http;r=d1_http.query(\"SELECT updated_at,value FROM site_settings WHERE key='domain_pocket'\")['results'][0];v=json.loads(r['value']);print(r['updated_at'],len(v['rows']),v['queue_status'])"
```
`queue_status.scored_today` 大於 0、`queued` 比 391 少。
如果一個都沒查到：看 log 裡 Claude 的回報是哪一種——「Ubersuggest 沒有連上」→ 回第 2 步；"daily reports limit" → 這個帳號今天額度用完（新帳號額度小的話很正常，寫進回報）。

### 4. 裝每天 09:30 的排程
```bash
cd ~/claude-projects/工作流程技能包/step1ne-recruit
mkdir -p ~/.config/systemd/user
cp systemd/step1ne-domainfinder.service systemd/step1ne-domainfinder.timer ~/.config/systemd/user/
grep -q 'v22.22.0' ~/.config/systemd/user/step1ne-domainfinder.service && ls ~/.nvm/versions/node/   # node 版本不是 v22.22.0 就把 service 裡 PATH 那行改成實際版本
systemctl --user daemon-reload && systemctl --user enable --now step1ne-domainfinder.timer && systemctl --user list-timers | grep domain
```
`Persistent=true`：09:30 電腦沒開，開機後會補跑。單次上限 5 小時。
跑的時候 claude 是用 Jacky 的 Claude 帳號（跟阿財同一份用量）；模型 `claude-sonnet-5`（要換就在 service 加 `Environment=DF_MODEL=…`）。

### 5. 每天的 TG（不用另外設定）
`run_daily.sh` 最後跑 `sync_dashboard.py --tg`：**只有出現新的「前世乾淨、分數 20～40、還沒買」網域才發**，發到 Jacky 私訊 8365775688，三行：
```
🌐 網域獵人：今天多了 N 個前世乾淨、可以直接註冊的網域
aaa.com（31 分）、bbb.com（25 分）…
DR 還沒查，請到 Ahrefs 查完填在看板上 → https://step1ne.com/seo-report/#domains
```
已經通知過的會記在 D1 那份資料裡（`notified_clean`），不會重複發。讀不到 D1 那天整個不同步也不發（免得重發），隔天再試。

### 6. 驗收
- `list-timers` 顯示下次 09:30。
- 隔天 09:30 後：`tail -60 ~/aijob-automation/logs/domain_finder.log` 有 Claude 的回報＋`ok 看板已同步`。
- 看板「口袋名單」上方那行顯示「佇列剩 N 個、今天查了 N 個…」，數字有變。
