# E38｜Jacky 10/20：帶案儀表板每天自動更新（WSL2）

## 目標
給 Jim 看的帶案儀表板 https://pipeline.step1ne.com （通行碼門禁）每天自動更新，**Mac 不跑**。
一週一頁：本週每天更新；跨週後第一次跑會把上週封存（之後不再變），下週一自動開新的一頁。

## 程式在哪（git pull 就有）
`pipeline_dash/`
- `build.py`：從 D1 重算本週（這週新增＋累計＋未簽約開發客戶）→ 存 D1 `pipeline_weekly`（壓縮）→ 組 `index.html` → `npx wrangler deploy`
- `template.html`：頁面樣板；`worker.js`＋`wrangler.toml`：通行碼門禁的 Worker（step1ne.com 那個 Cloudflare 帳號）
- `index.html` 是產出物，不進 git（.gitignore）

人工欄位（球在誰、說明、Email 推薦、新客戶、人選狀態覆寫）在 D1 `site_settings` key＝`pipeline_dash_overlay`，Mac 這邊會改，WSL2 不用動。

## 要做的
1. `git pull`，確認 `pipeline_dash/` 在。
2. 確認有 `~/.config/workflow-os/step1ne-frontend-cf.env`（jdregen 上線用的那把，step1ne.com 帳號 673dc235…）。**沒有就停下來回報**，請 Jacky 自己搬，不要在對話貼 token。
3. 確認 `npx wrangler --version` 能跑。
4. 先手動跑一次：
   ```bash
   cd ~/claude-projects/工作流程技能包/step1ne-recruit && python3 pipeline_dash/build.py
   ```
   看到 `本週已更新`、`已上線 ['Current Version ID: …']` 才算成功。
5. 建 systemd user timer `step1ne-pipelinedash`：每天 **09:00、13:00、18:00、23:30** 跑上面那行（`Persistent=true`）。
   週一 09:00 那次會自動封存上週，不用另外設。
6. 回報寫到 `docs/wsl2/回報/E38_回報.md` 並 push：timer 狀態（`systemctl --user list-timers | grep pipelinedash`）＋第一次跑的輸出最後三行。

## 注意
- 不要改 `pipeline_weekly` 裡 `frozen=1` 的週，那是封存的週報。
- 部署失敗（token 過期、網路）會印「部署失敗：…」並以非 0 結束；資料還是有存進 D1，下次跑會補上線。
- 頁面上有人選全名，**不准拿掉通行碼門禁**（worker.js 的 DASH_PASS）。
