# E46：社群草稿多一個選填欄位「今天想搭的話題」（10/22 已上正式）

日期：2026-10-22（Mac 總指揮）

## 一句話
**WSL2 不用做任何事。** `social_post_agent.py` 自動更新後就會讀新欄位；env、排程都不用改。

## 改了什麼
- D1 `social_post_queue` 多一欄 `topic_hook TEXT`（已在 Mac 執行 `migrations/2026-10-22_social_topic_hook.sql`）。
- 顧問在**測試版後台**（/consultant-beta/ 的一鍵發文、今日話題挑題視窗）可選填一句話題，例：「颱風天看職缺」。
- `social_post_agent.py`：佇列那一列有 `topic_hook` 才在 prompt 加一段「當開頭鉤子、不准編造該事件任何事實」的規則；TG 審核卡多一行「🌀 搭的話題：…」。
  - **沒填（NULL）＝ prompt 一個字都沒變**，正式版後台不送這個欄位，所以正式行為不變。
  - 「🔄 重新產一次」是同一列重跑，所以會沿用同一個話題。
- 後台 Worker `/admin/social-post-request` 收 `topic_hook`（最多 40 字），防重複判準把它算進去。
