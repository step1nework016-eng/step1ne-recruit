# E50：阿福履歷健檢新版（測試版）——WSL2 拉新版、重啟阿福

日期：2026-10-23（Mac）

## 一句話
`git pull` 之後**重啟 WSL2 的阿福（checkup_daemon.py）**就好。不用改設定檔、不用加金鑰。
（阿福也會自己偵測新版重啟〔autoupdate〕，有人在健檢對談中會等閒下來才換，**不要硬砍正在對談的程序**。）

## 這次改了什麼（只影響從測試版 /checkup-beta/ 進來的場次，form_version='v2'；舊表單行為不變）
1. `checkup_daemon.py`
   - 對談／報告的 prompt 多讀四格：想找的工作、期望地點、期望薪資、學歷（舊表單這四格是空的，prompt 不變）。
   - 快速回覆按鈕：開關 `site_settings.afu_quick_replies`（目前 `test`＝新版表單或姓名含「測試」才給），
     借用 `acai_quick_replies.py` 的提示詞與把關，存在新表 `afu_quick_replies`。
   - 報告最後加「七、跟你方向接近的職缺」：新檔 `afu_job_recs.py`（沿用 `acai_job_recs.py` 的候選職缺／把關／白名單），
     結果另存 `checkups.job_recs_json`。沒有合適的就整段不出現。
2. `make_checkup_report.py`：第七段排版＋一鍵應徵按鈕；薪資把關只掃前六段。
3. `checkup_parse.py`：只貼「履歷連結」沒上傳檔案時，用 parse_resumes.py 既有抓法讀連結。
4. D1：`checkups` 加 6 欄、新表 `afu_quick_replies`、開關 `afu_quick_replies`——Mac 已建好，WSL2 不用動。

## WSL2 要做的
1. `cd <step1ne-recruit>` → `git pull`（要拉到 commit「阿福健檢新版（測試版）」或更新）。
   檢查：`ls afu_job_recs.py` 存在、`grep -n "quick_eligible\|afu_job_recs" checkup_daemon.py` 都找得到。
2. 重啟 WSL2 阿福（checkup_daemon.py，照原本啟動它的方式；systemd 的話 `systemctl --user restart` 那個服務）。
3. 阿財（interview_daemon.py）、parse_resumes.py、ai_worker.py 這次沒改，不用重啟。
4. 驗收：阿福 log 沒有 Traceback；之後有新版表單場次時，log 會出現 `快速回覆按鈕 [...]` 或 `[阿福推薦職缺]` 字樣（正常）。
