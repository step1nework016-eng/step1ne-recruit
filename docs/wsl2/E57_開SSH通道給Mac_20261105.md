# E57｜讓 Mac 能連進這台 WSL2（2026-11-05）

Jacky 要求：Mac 的 Claude Code 之後要能直接連進來做事，不用他每次走過來。
這份做完，接著照 E55、E56 做。

範圍只有開通道。不要動阿財、排程、任何常駐程式，不要重開機。

## 要做的事
1. 裝 Tailscale（私人網路，只有同帳號的機器連得到，不對外開門）：
   `curl -fsSL https://tailscale.com/install.sh | sh`
2. `sudo tailscale up --hostname=step1ne-wsl2`，把印出來的登入網址顯示給 Jacky，讓他自己在瀏覽器登入。不要代他輸入帳號密碼。
3. 裝 openssh-server，新增 `/etc/ssh/sshd_config.d/90-mac-tunnel.conf`：
   ```
   ListenAddress 127.0.0.1
   PasswordAuthentication no
   KbdInteractiveAuthentication no
   PermitRootLogin no
   AllowUsers jack
   ```
   先跑 `sudo sshd -t` 檢查，再 `sudo systemctl enable --now ssh`。
4. 把下面這一行公鑰加進 `~/.ssh/authorized_keys`（資料夾 700、檔案 600）。只加這一把：
   ```
   ssh-ed25519 AAAAC3NzaC1lZDI1NTE5AAAAIDWya0+5jCDIE21DppDgnu8x8vdDSZ+TX0hSd7yZDiQ2 mac-to-wsl2-step1ne
   ```
5. 只讓 Tailscale 網路內連得到：`sudo tailscale serve --bg --tcp 22 tcp://localhost:22`
6. 確認 Windows 不會讓 WSL2 睡著斷線：`systemctl is-enabled tailscaled ssh` 都要是 enabled。

sudo 要密碼時請 Jacky 自己輸入，不要叫他把密碼貼進對話。
