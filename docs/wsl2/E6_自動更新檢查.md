## 要做的事

### 1. 先看現況（只看，不改）
```
cd ~/claude-projects/工作流程技能包/step1ne-recruit
git remote -v
git config --get core.sshCommand
git status --short | grep -v '^??' | head -30
git log -1 --format='%h %ci %s'
git fetch origin main 2>&1 | tail -3
git log -1 --format='%h %ci %s' origin/main
git rev-list --count HEAD..origin/main
```
把輸出原樣貼進回報。`HEAD..origin/main` 大於 0 ＝ 落後幾個版本。

### 2. fetch 失敗的話：修連線
- 錯誤是 `Repository not found` 或要帳密 → 遠端改走 SSH，用既有的 deploy key：
  ```
  git remote set-url origin git@github.com:step1nework016-eng/step1ne-recruit.git
  git config core.sshCommand "ssh -i ~/.ssh/id_ed25519_step1ne_recruit -o IdentitiesOnly=yes"
  git fetch origin main
  ```
- 那把 key 不存在、或還是被拒 → **停下來，不要自己產新金鑰、不要改用別人的帳號**，在回報寫清楚錯誤訊息。
- `~/claude-projects/step1ne-stopgap-site`（官網）和 `step1ne-backoffice-worker` 如果這台也有，用同樣方式各檢查一次 `git fetch`，有問題一起寫進回報。

### 3. 有本機改動的話：不要丟
第 1 步 `git status` 如果列出**程式檔**（.py／.js／.sh）有改動：
- 先 `git diff --stat` 貼進回報
- 只有 `__pycache__`、log、暫存檔 → 可以 `git checkout -- <檔名>` 還原
- 有真正的程式改動 → **不要還原、不要 stash 後丟掉**，停下來在回報列出檔名，等總指揮看

### 4. 更新到最新
```
git pull --rebase origin main
grep -c "job_reverse_match" ai_worker.py          # 要 ≥ 1
grep -c "_page_live" step1ne_medic.py              # 要 ≥ 1
```

### 5. 讓常駐程式換成新版
- **阿財（interview_daemon.py）**：先查有沒有人在面談
  ```
  python3 ../_tools/d1_readonly.py "SELECT COUNT(*) n FROM applications WHERE interview_state='active'"
  ```
  不是 0 → **不要重啟阿財**，它會在沒人面談時自己更新；回報寫「等它自己換」。
- **其他常駐程式**（ai_worker、talent_sourcing_tg_worker、social_post_agent、jd_regen_tick、portal_import_tick、checkup／阿福、placement tracker）：
  用這台原本的方式（systemd／排程）重啟。阿福如果有人在健檢對話中，同樣先不要重啟。
- 排程類（medic、report_tick…）下一次執行就會用新版，不用動。

### 6. 驗收
1. `python3 step1ne_medic.py --dry` → 不應該再出現「在官網上不存在」
2. 確認 ai_worker 新版在跑：看它的 log 最近一次啟動時間是剛剛
3. 看自動更新 log（`autoupdate.py` 印的訊息）有沒有「已是最新」或成功 pull 的紀錄；
   **找出它之前為什麼沒更新**（是 fetch 失敗、還是根本沒在檢查），寫進回報
4. 回 Mac 這邊不用做事——Mac 已經把那 27 個配對改在 Mac 上重跑了，這台**不要**再去重跑

- 不要產新的 SSH 金鑰、不要用別人的 GitHub 帳號
- 有人在面談時不要重啟阿財
- 不要手動發 TG、不要寄任何信
