# Evidence Rules

Every campaign candidate reported by the skill must include concrete evidence.

## Good evidence characteristics

Evidence should be:

- public;
- specific;
- concise;
- directly related to campaign fit;
- traceable to a source URL when possible.

## Strong examples

- `Bio標示「保養/美妝實測」，近期公開內容持續分享防曬、精華與敏感肌產品心得。`
- `Bio提供合作信箱，公開內容可見多次品牌標註與折扣碼合作。`
- `近期多篇貼文為商品實測與開箱，內容風格符合案件偏好的 product_review signal。`

## Weak examples

Do not use:

- `看起來很適合`
- `粉絲很多`
- `名字有 beauty`
- `感覺受眾是女生`

## Source URL

Prefer the most direct public URL supporting the evidence:

1. creator profile;
2. specific public post/reel when used as evidence;
3. external creator site/link page when relevant.

## Quotes

Keep evidence paraphrased/short. Do not copy long passages from public pages.
