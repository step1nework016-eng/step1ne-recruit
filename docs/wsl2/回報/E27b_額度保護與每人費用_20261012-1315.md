## 1. 額度保護
設定檔 `~/.config/workflow-os/acai_budget.json`（沒有檔案就用預設，之後儲值可改）：
```json
{"budget_usd": 20, "warn_usd": [10, 16], "cutoff_usd": 19, "since": ""}
```
- 累計花費 = `token_usage` 中 `source='api'` 的 `cost_usd` 加總（`since` 有填就只算那之後）。每次 API 呼叫記錄後，**背景執行緒**每分鐘最多查一次 D1，不拖慢面談。
- 達 **US$10、US$16** 各發一則 TG 給 Jacky（各一次）。
- 達 **US$19**：把 `~/.config/workflow-os/acai_llm` 寫成 `cli`，發 TG：「已自動改回 CLI……儲值後回我『阿財改回 API』才會切回去」。**不會自動切回**。
- **API 回「額度不足」**：這一輪自動走 CLI（E27 已有）；另外立刻把模式寫成 `cli`、**同一天只發一則 TG**：「API 額度用完，已自動改回 CLI，面談不受影響。要繼續用 API 請到 Console 儲值，再回我『阿財改回 API』」。
- 儲值後恢復：`python3 acai_budget.py --resume-api --budget 40`（模式設回 api，預算線改成新總額的 50%／80%／總額−1，並從現在起重新累計、提醒重新武裝）。不加 `--budget` 只切模式。
- 提醒訊息範例：
  `💵 阿財 API 花費提醒：累計已 US$10.52（提醒線 US$10，預算 US$20，剩約 US$9.48）。到 US$19 會自動改回 CLI。`

## 2. 每位人選費用

- **台幣**：執行當下抓即時匯率，印出匯率、來源、更新時間與抓取時間；抓不到就只給美元並寫「匯率未取得」，沒有寫死任何數字（有測試）。

## 3. 單價統一
`claude_api.PRICES` 成為唯一一份：claude-sonnet-5 輸入 $2／輸出 $10／快取寫入（1 小時）$4／快取讀 $0.2（每百萬 token），`acai_token_report.PRICE` 改成引用它。依 **API 回應實際回報的模型**（前綴比對）取價；對不到的模型用預設價並在報表標「⚠️模型單價未確認」。
- 注意：目前 API 版**沒有用 cache_control**，所以 API 的快取寫入／讀取量會是 0，每輪都付全額輸入價——這是 API 版比 CLI 牌價「看起來省」卻仍可能偏貴的原因，提示詞快取是下一個值得做的省錢項目（需動 `build_prompt` 結構，品質風險要先比對）。
- 打通後要拿一場的 **Console 帳單對一次**（尤其確認 `claude-sonnet-5` 這個 API 模型 ID 與單價是否正確）。
