## 一句話結論

**不是 GitHub 連不上，自動更新一整天都有在檢查、也有 pull。** 真正的原因是自動更新的判斷方式有漏洞：
各常駐程式共用同一個工作目錄，**只要其中一支先 `git pull`，其他支比對 `HEAD` 跟 `origin/main` 就會發現「一樣」，
以為自己是最新的、不重啟——但它們記憶體裡跑的還是舊程式**，沒有任何錯誤訊息。

## 建議給總指揮（我沒有改程式碼）

要根治，需要改 `autoupdate.py`（以及 ai_worker 內建的那份）：**啟動時記下自己載入的 commit（`START_HEAD`），
之後比對的是「`START_HEAD` vs 現在 `HEAD`／`origin/main`」，不是「`HEAD` vs `origin/main`」**。
只要工作目錄被別的程序更新過（`HEAD != START_HEAD`），就算 pull 已經完成也要重啟自己
（阿財仍照原本規則等沒人面談再重啟）。這個漏洞在 Mac 那台只有一支自動更新的程式時看不出來，
在這台 6～7 支共用同一個目錄時就會一直發生。
