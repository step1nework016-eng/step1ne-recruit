## 一句話
**根因：Claude Code（npm 全域安裝）會在背景自我更新，更新的 2～4 秒 `claude` 執行檔暫時不存在，剛好撞到的草稿呼叫會報 `[Errno 2] No such file or directory: 'claude'`；社群程式又不重試，那幾則就卡在「認領中」。** 已做兩項修補：社群產稿加重試、關掉這台 Claude 的自動更新。

## 修補 1：社群產稿碰到「找不到 claude」或逾時，等 20 秒重試 2 次（commit 1b516f0）
- `social_post_agent.py`：原 `run_claude` 改名 `_run_claude_once`，新 `run_claude(prompt, retries=2, wait=20)` 包起來，只對 `FileNotFoundError`、`TimeoutExpired` 重試，claude 回非 0 照舊直接丟出。
- 離線測試（模擬）：前 2 次找不到、第 3 次成功 → 成功（呼叫 3 次）；一直找不到 → 重試後丟出（3 次）；claude 回非 0 → 不重試（1 次）。
- 這是社群產稿核心流程，請 Mac 審。

## 修補 2：關掉這台 Claude 的自動更新
- `~/.claude.json`：`autoUpdates=false`（備份 `~/.claude.json.bak-20261022`，權限 600，原子寫入）。
- 環境變數 `DISABLE_AUTOUPDATER=1`（這個版本 2.1.308 的程式本體認得這個變數與 `autoUpdates`）：
  - systemd 使用者環境（`systemctl --user set-environment`）＋ `~/.config/environment.d/90-claude-noupdate.conf`（重開機後仍有）；
  - crontab 最上面加 `DISABLE_AUTOUPDATER=1`（備份 `~/crontab_backup_20261022c.txt`）；
  - `daemon_ctl.sh` 重啟一律帶這個變數（commit 914616f）。
- 已重啟並確認帶到變數（`/proc/<pid>/environ`）：阿財面談（systemd，當時無人面談）、ai_worker、clientreport、matchworker、jobintake、社群程式（21:32 重啟，新版含重試）。沒重啟的（cron 守護、較少呼叫 claude）：talentsourcing、checkup、articlepublish、jdregen——它們靠 `~/.claude.json` 的 `autoUpdates=false` 生效，下次重啟會一併帶環境變數。
- 之後要更新 Claude：手動 `claude update`（建議挑沒有面談的時段）。
