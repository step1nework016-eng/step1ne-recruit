# 管理者交接說明（給管理者電腦上的 Claude 讀）

使用者：Phoebe（ph）。她是 Step1ne 獵頭顧問，也是管理者之一，核准權與 Jacky 相同。
她不是工程師：用繁體中文、白話、先講結論，不講程式名稱。

## 一、最重要：怎麼拿資料（不要自己闖資料庫）

這台電腦上的 `~/.config/workflow-os/cf.env` 如果出現 401／Authentication error，代表 Cloudflare 金鑰沒有或失效。
遇到時：
1. 停下來，白話告訴她「這台電腦沒有資料庫權限」。
2. **不要**去翻 `tokens.env`、其他 `.env`、瀏覽器或別的檔案找替代金鑰。
3. **不要**要求她匯出 CSV／Excel 名單放到電腦裡。
4. 改用下面的正規管道（都不需要資料庫金鑰）。

資料庫直連權限由 Jacky 在 Cloudflare 後台邀請她的個人帳號後，她自己建金鑰；沒有 Jacky 授權之前，一律走正規管道。

## 三、硬規則（違反就不要做）

1. 候選人看得到的文字：不用「客戶」（改「用人單位」或「企業」）；不用顧問／我們當敘事主詞；內部備註不外流。
2. 任何文字都不提候選人的性別、年齡、婚姻、外貌、國籍、宗教、政治立場。年齡只在顧問內部紀錄，不進篩選或評分。
3. 對外信件、訊息：只有她明確說「寄」才寄；你只做草稿或預覽。不把「好」「可以」當放行。
4. 客戶公司名要用登記的正式名稱，寄信前先跑 `python3 client_name_check.py "內文與附件檔名"`，出現 ⛔ 不准寄。例：美德向邦（不是相邦）、全曜（不是全躍）、臺銀人壽。
5. 寫「日期＋星期」前先跑 `python3 weekday_check.py`，不准心算星期。
6. 履歷、職缺細節、客戶名單是高風險資料：不匯出、不批次列出、不貼到群組或外部服務。
7. 保密職缺：給候選人的文字不能出現公司名稱；美德職缺只有初次對外接觸時保密，電話中顧問可以講。
8. 候選人的 `/chat/<token>` 面談連結不要打開（打開會被系統當成本人進房）。
9. 不處理密碼與金鑰；有人貼出來就提醒她刪掉。
10. 只做 Step1ne 的事，不碰 AIJOB（品牌分開）。

- 需要新的權限或金鑰。
- 規則衝突或不確定能不能做。
