# 104 下載的履歷：分類 → 寄信（A/B）→ 匯入系統｜給 Claude 的作業說明書

建立：2026-10-23（Jacky 與他的 Claude 實際跑過兩批、20 封後整理）
給誰用：Phoebe 的 Claude（也適用 Jacky 的 Claude）。Phoebe 說「處理 104 履歷」「幫我寄 104 的信」時照這份做。
先讀：`prompts/Phoebe的Claude_設定與權限對照.md`（寄信、權限、禁止事項以那份為準）。

## 0. 一句話流程

Phoebe 從 104 下載履歷 PDF → 放進「無接通」資料夾 → **你**讀履歷、照職缺條件分組 → 給 Phoebe 看分組 → 擬 A/B 兩版信、做預覽 → Phoebe 說「寄」→ 用 `free-mail` 從 official@ 逐封送確認卡 → 寄完把履歷移到「已寄出」、記追蹤表 → 把已寄出的人匯入系統人才池。

你負責：讀、分、寫、預覽、送確認卡、搬檔、記錄、匯入。
Phoebe 負責：下載履歷、決定推哪個職缺、說「寄」、在 TG 按確認、打電話。

## 1. 資料夾（第一次先建好）

在 Phoebe 指定的位置（例如桌面）建一個 `104` 資料夾，底下五個：

| 資料夾 | 放什麼 |
|---|---|
| `無接通` | 剛下載、還沒處理的（電話沒接到的人）。**你只處理這裡面的檔案** |
| `有接通` | 電話有接到的，Phoebe 自己跟進，你不用寄信 |
| `已寄出` | 寄過信的 |
| `不寄信` | 條件不符、或 Phoebe 說不寄的 |
| `無法聯繫` | 履歷上沒有 Email（104 隱藏聯絡方式，要在 104 按「邀約」才拿得到） |

檔名規則：`姓名.pdf`；Phoebe 想指定推哪個職缺，就寫在檔名後面，例如 `王小明 宇泰華.pdf`、`李小華 財會人員.pdf`。**檔名有標職缺就照她標的推，不要改判。**
注意：104 下載的檔名常常開頭多一個空白（` 王小明.pdf`），搬檔時要處理；「列印預覽 _ 104招募管理.pdf」這種檔名要讀內容找出姓名再改名。

---

## 2. 讀履歷（每份都要讀，不要只看檔名）

用 `pdftotext -l 2 檔案.pdf -` 讀前兩頁，抓這幾項：
姓名、最高學歷（學校＋科系＋畢業/就學中/肄業）、希望職稱、總年資、最近工作、居住地、Email、有沒有機車駕照。

- 讀不到字（圖片型 PDF）→ 標「要人工看」，不要猜。
- Email 欄寫「請先使用邀約功能」或抓不到 → 放 `無法聯繫`。
- 同一個人下載兩次（檔名一樣或內容一樣）→ 第二份放 `不寄信`，檔名加「_重複下載」。

看「學歷」「必要條件」「工作地點」「對人選這樣說（薪資口徑）」。

2026-10-23 當時常用的幾個（只當參考，以 `job` 查到的為準）：

## 4. 寫信：A/B 兩版

### 4-1. 分組做 A/B 測試
- 同一批人平均分成 A、B 兩組；理工／非理工、經歷多寡兩邊各放一半。
- 每個人只收一版。
- **樣本太少不要下結論**：要累積到大約 100 封送達才判斷哪一版回覆率高。10 封、20 封只能說「還在累積」。

### 4-2. A 版（完整資訊＋應徵連結）
主旨：`新竹科學園區 BIM 工程師｜沒經驗也可以，從 AutoCAD 開始學`
```
{姓名} 您好，

我是全民獵才的 {顧問名}。今天有撥電話給您，可能剛好在忙沒接到，所以改用信件分享一個新竹的工作機會。

看到您{個人化一句}，覺得這個職缺值得先讓您知道：

【BIM 工程師（儲備培訓）｜新竹科學園區】
・不需要相關經驗：從 AutoCAD 2D 圖面學起，再進階 Revit 3D 建模
・參與半導體廠的機電、管線 BIM 模型，一開始就累積半導體建廠的實戰經歷
・學士月薪 40,833～50,167 元（依學歷核定，碩士級距更高）
・08:30–17:30，週休二日、不輪班；加班費依勞基法、以全薪計算
・團體保險 500 萬、員工旅遊、生日禮金
・條件：大學以上、科系不限，有機車駕照

BIM 學會之後，在半導體建廠、營造、工程設計相關的工作都用得上，是一個可以帶著走的專業。

有興趣的話，點這裡 1 分鐘就能完成應徵：
https://step1ne.com/apply-quick/?job=semiconductor-bim-mep-drafting-trainee-hsinchu&v=A

想先多了解，也歡迎直接回信，或留一個方便接電話的時段，再打給您聊聊。

想多認識全民獵才，可以看官網 https://step1ne.com/ ，或在 Google、AI 工具上搜尋「全民獵才」或「Step1ne」都找得到哦！

祝 順心
{顧問名}｜全民獵才 招募團隊
```

### 4-3. B 版（短、像朋友傳訊息，請他回一句話）
主旨：`{姓名}，有興趣在新竹科學園區學 BIM 嗎？`
```
{姓名} 您好，我是全民獵才的 {顧問名}，今天打給您沒接到，所以改寫信 😊

看到您{個人化一句}，想跟您分享：新竹科學園區有一個 BIM 工程師（儲備培訓），沒經驗也可以，從 AutoCAD 學起，學士月薪 40,833～50,167 元，週休二日、不輪班。

如果有興趣，直接回這封信一句「有興趣」就好，再跟您約時間電話聊細節。

想多認識全民獵才，可以看官網 https://step1ne.com/ ，或在 Google、AI 工具上搜尋「全民獵才」或「Step1ne」都找得到哦！

{顧問名}｜全民獵才 招募團隊
```
換別的職缺：保留同樣的結構，條列換成 `consultant_ops.py job` 查到的內容；有快速應徵頁的職缺連結後面加 `&v=A`（沒有快速應徵頁就給職缺頁 `https://step1ne.com/jobs/<slug>/?v=A`）。

### 4-4. 每封信最下面加正式頁尾（Jacky 10/23 要求，讓人選相信是正式信）
```
———
德仁管理顧問有限公司（全民獵才｜Step1ne）
統一編號：85046127｜就業服務許可證：北市就服字第 0363 號
臺北市內湖區康寧路三段 54 之 7 號 3 樓｜02-6605-7111｜https://step1ne.com/

本信件僅寄給指定收件人，內容可能包含職缺與個人資料，請勿轉寄或公開。如果您不是指定收件人，請直接刪除本信，並告知寄件人。

提醒您：應徵與職缺推薦過程，不會向您收取任何費用，也不會要求您提供銀行帳號或密碼。如有疑問，請撥 02-6605-7111 確認。
```

### 4-5. 個人化那一句怎麼寫
- 只寫履歷上**真的有寫**的事：學校科系、最近一份工作、希望職稱、住哪一區。
- 好例子：「中山環工碩士畢業，也在廣達做過自動化工程，對工程現場不陌生」「剛從淡江畢業，正在找第一份正職」「在科技公司做過總機和行政，對科技業的環境不陌生」。
- **不准寫**：年齡、性別、婚育、外貌、國籍；不准誇大（「做事細心」這種履歷沒證據的形容詞不要寫）。

### 4-6. 人選文字硬規則（全部信都適用）
- 開頭「我是全民獵才的 {顧問名}」，不寫「Step1ne 的」。
- 不出現「客戶」兩個字（改「用人單位」「這家公司」）。
- 不寫客戶公司名（用「半導體廠務工程公司」「高科技廠房工程公司」這種說法）。
- 薪資只照 `job` 查到的「對人選這樣說」那一句，不解釋怎麼算。
- 不寫「排名第一」「最大」這類查不到的話。

## 5. 預覽 → Phoebe 說「寄」→ 送確認卡

1. 把每封信（姓名、Email、A/B、主旨、全文）做成**一個 HTML 預覽檔**給 Phoebe 看（手機能看；人看的東西一律給 HTML，不要給 md）。
2. 等 Phoebe 明確說「寄」。「好」「可以」不算，要看到「寄／寄出／發」。
3. 逐封送確認卡，**寄件信箱是 official@step1ne.com**：
   ```
   python3 consultant_ops.py free-mail --to 人選Email --subject "主旨" --text-file 信件.txt --card-note "104無接通 BIM A版"
   ```
   這些人還不在系統裡，所以用 `--to`，不用 `--who`。
4. 確認卡會出現在 TG，Phoebe（或 Jacky）按確認才真的寄出。
5. **禁止**：用 Gmail 連接器寄；用 jackychen@ 寄；一次群發、把多個人放同一封信的收件人。

## 6. 寄完之後

1. 把寄出的人的 PDF 從 `無接通` 搬到 `已寄出`。
2. 在 `104/寄信追蹤.csv` 加一行（沒有這個檔就建立）：
   ```
   日期,職缺slug,版本,姓名,Email,寄出時間,有回信,有點連結,備註
   ```
3. 回覆會進 official@，系統每 5 分鐘讀一次並推 TG。看到有人回信，把「有回信」填上，並提醒 Phoebe 打電話。
4. Phoebe 問「哪一版比較好」時：先講目前各幾封、各幾個回覆，**沒到 100 封就明講「還在累積，還不能下結論」**。

## 7. 匯入系統（把找到的人放進人才池）

寄出的人都要匯進系統的**人才池**，之後新職缺的 AI 配對才找得到他們。

```
python3 resume_to_pool.py ~/Desktop/104/已寄出/王小明.pdf --job <推薦的職缺slug> --dry   # 先試一份，只看解析結果、不寫入
python3 resume_to_pool.py ~/Desktop/104/已寄出/王小明.pdf --job <推薦的職缺slug>         # 確定沒問題再寫入
```
- 進的是「人才池」，不是「應徵者」。他們還沒應徵，不要用 `/apply`、不要用 TG「電洽新增人選」。
- 人選如果點信裡的連結自己應徵，系統會自動建成正式應徵（會有阿財面談），不用你另外處理。
- 人選回信說有興趣、Phoebe 跟他通完電話之後，才走 TG「📞 電洽新增人選」把他正式建進系統。
- 匯入要用到後台的鑰匙（Phoebe 的 AI 專用那把，`STEP1NE_API_TOKEN`）。如果出現「沒有權限／401」，停下來跟 Phoebe 說要找 Jacky 拿，不要找別的方法繞過。
- 一份履歷解析大約要 1～2 分鐘，一次匯入很多份時，跑完回報「成功幾份、失敗幾份、失敗的是誰」。

## 8. 回報格式（短）

- 分組完：「無接通 N 份：BIM 符合 X 位、宇泰華 Y 位、不符 Z 位（名單見下）。要寄哪幾組？」
- 寫好信：「A/B 各 N 封，預覽在 <檔案>。說『寄』就送確認卡。」
- 寄完：「N 張確認卡已貼 TG，按確認就寄出；履歷已移到已寄出，追蹤表已更新。」
- 匯入完：「人才池匯入 N 份（失敗 M 份：…）。」
不要長篇解釋，不要列一堆「接下來會發生什麼」。
